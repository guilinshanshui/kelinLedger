# 不发布上线 · 长期免费用微信云开发部署指南

适用项目：可林记账本（Roomie）
目标：只给自己和媳妇用，**不提交审核、不发布上线**，同时**一直免费用微信云开发**。

---

## 一、先看结论（政策依据）

按微信官方文档《计费说明》，微信云开发是「基础套餐 + 按量付费」模式，但有专门的免费活动：

| 规则 | 内容 |
|---|---|
| 免费环境资格 | 每个**没有云环境**、或云环境**注销超过 1 个月**的小程序账号，可创建 1 个免费云环境 |
| **未发布阶段** | **免费云环境在小程序未发布上线阶段，无需开发者续费** |
| 已发布阶段 | 免费环境在小程序**发布后第 15 天**到期，必须转付费 |
| 免费配额 | 与基础套餐一致：调用 20 万次、容量 2GB、外网出流量 2GB、云函数资源 10 万 GBs、CDN 5GB、QPS 500 |
| 活动截止 | 2026 年 12 月 31 日，如有调整会提前 3 个月在微信开放社区和腾讯云官网通知 |
| 重要限制 | 免费环境**不支持资源额外加购** |

> 一句话：**只要小程序一直不点「发布」，这个云环境就一直免费、不用续费。**

本文所引政策的官方原文页面：
- 计费说明：https://developers.weixin.qq.com/miniprogram/dev/wxcloud/billing/price.html
- 小程序版本与体验版：https://developers.weixin.qq.com/miniprogram/dev/framework/quickstart/release.html

## 二、两个必须分清的按钮

| 操作 | 入口 | 会不会导致收费 | 说明 |
|---|---|---|---|
| **上传代码** | 开发者工具顶部「上传」 | 不会 | 把代码传到「开发版本」，不是发布 |
| **设为体验版** | 小程序后台 → 版本管理 → 开发版本 → 设为体验版 | 不会 | 只有体验成员能打开，等同内测 |
| 提交审核 | 小程序后台 → 版本管理 | **会** | 审核通过后一旦发布，免费环境 15 天后到期 |
| 发布 | 小程序后台 → 审核版本 → 发布 | **会** | 触发免费环境到期倒计时 |

**你要做的全程只在「上传」和「设为体验版」两处，永远不要碰「提交审核」和「发布」。**

## 三、操作步骤

### 步骤 1：确认当前云环境是免费环境

1. 打开微信开发者工具 → 顶部「云开发」→ 进入云开发控制台。
2. 左侧「设置」→「环境设置」→「配额方案」。
3. 确认显示为**免费环境 / 开发阶段免费**，没有到期时间，或是长期有效。

> 实际界面路径（已核对）：云开发控制台 → 左栏「**费用管理**」。页面上方 tab 为「套餐管理 / 我的订单 / 支付方式 / 代金券 / 发票」。
> 顶部环境选择器右侧会显示环境类型 badge。

本项目环境 `cloudbase-d0g5v4tf442146566` 已验证的状态：

| 项目 | 状态 |
|---|---|
| 环境类型 | 免费开发环境（badge 显示在顶部环境选择器旁） |
| 调用次数 | 20 万次 / 月 |
| 容量 | 3 GB |
| 云函数资源使用量 | 15 万 GBs |
| 云函数外网出流量 | 4 GB |
| CDN 流量 / 回源流量 | 10 GB / 10 GB |
| **按量付费** | **必须保持关闭**（关闭时不超配额就不会产生费用） |
| **自动续费** | **必须保持关闭**（免费环境无需续费） |

> 「¥19.9/月」和「购买」按钮是**转付费**时的价格，不要点击。
> 建议点右上角「配置告警策略」，按用量百分比设告警（例如 80%），提前收到用量提醒。

如果这里显示的是一个**已到期的付费套餐**，说明当初创建的不是免费环境。处理办法：注销该环境并等满 1 个月，再新建一个免费环境（数据会丢失，先备份）。

### 步骤 2：构建最新代码

```powershell
cd E:\chatgpt\记账本小程序\roomie
npm run build:mp-weixin
```

产物固定在 `dist/build/mp-weixin`，不要用 `dist/dev`。

### 步骤 3：用开发者工具打开最新产物

```powershell
npm run open:mp
```

这条命令会「先重新构建 → 校验产物 → 再打开开发者工具」，避免出现「看到的是旧包」的问题。

### 步骤 4：确认云函数已是最新

开发者工具左侧资源管理器，根节点是 `MP-WEIXIN`，展开 `cloudfunctions`：

1. 右键 `roomie` → 选**「上传并部署：云端安装依赖」**。
2. 如果菜单里显示的是「创建并部署：所有文件」，说明 IDE 认为云端还没有这个函数——先点顶部云环境选择器同步一次环境列表，再重试。
3. 云函数代码和触发器必须分别上传，两者都不会随小程序代码上传自动完成：
   - 右键 `roomie` →「**上传并部署：云端安装依赖**」→ 更新云函数代码
   - 右键 `roomie` →「**上传触发器**」→ 注册 `config.json` 里的定时触发器

   触发器配置在 `cloudfunctions/roomie/config.json`，共两个：

   | 名称 | cron | 频率 | 用途 |
   |---|---|---|---|
   | `dailyRecurring` | `0 5 1 * * * *` | 每天 01:05 | 周期账单入账 |
   | `reminderTick` | `0 0 * * * * *` | 每小时整点 | 生日、日程提醒派发 |

   > 两个触发器都没上传时，周期账单和提醒都不会自动跑，只能靠前端手动调接口补跑。
   > 触发器不会随云函数代码部署自动注册，这是微信平台的固定规则。

### 步骤 5：上传代码（不是发布）

1. 开发者工具顶部点**「上传」**。
2. 版本号填 `1.0.0`，项目备注填 `可林记账本体验版`。
3. 点确定，等待上传完成。

### 步骤 6：设为体验版

1. 打开 [小程序管理后台](https://mp.weixin.qq.com)。
2. 左侧「管理」→「版本管理」→「开发版本」。
3. 找到刚上传的 `1.0.0`，右侧点**「选为体验版」**。
4. 页面会生成一个体验版二维码。

### 步骤 7：添加体验成员

1. 小程序后台 →「管理」→「成员管理」→「体验成员」。
2. 把你的微信、媳妇的微信都加进去（添加时要对方先扫码确认邀请）。
3. 两人分别扫体验版二维码，即可长期使用。

体验成员不需要是项目成员，也不需要开发者权限，直接扫码就能用完整功能——包括云函数、云数据库、定时提醒。

## 四、这个项目的实际资源消耗评估

两人日常记账的使用量，相对免费配额几乎是零头：

| 计费项 | 免费配额 | 你们两人大致用量 |
|---|---|---|
| 云函数调用次数 | 20 万次 / 月 | 每次开页面几次调用，两人合计每月几百到几千次 |
| 数据库读写 | 计入上项 20 万次 | 同上 |
| 存储容量 | 2GB | 纯文本账目，几年也用不到几十 MB |
| 定时触发器 | 计入调用次数 | `reminderTick` 每小时一次 = 每天 24 次 ≈ 每月 720 次 |
| | | `dailyRecurring` 每天一次 = 每月约 30 次 |

定时触发器合计约每月 750 次，相对 20 万次配额完全可以忽略。

## 五、必须守住的红线

1. **永远不要点「提交审核」和「发布」。** 这是保持免费的唯一硬性条件。
2. **不要在云开发控制台手动把环境转成付费。** 免费环境的部分高级功能需要在控制台手动转付费才能用，本项目用不到，不要点。
3. **不要出现资源使用异常。** 官方明确：如识别到爬虫、挖矿、资源消耗异常等滥用行为，会**自动转为付费环境**，严重时直接封禁环境。你们正常记账不会触发。
4. **云环境的到期时间、配额请每季度看一眼。** 入口：微信开发者工具 → 云开发 → 设置 → 环境设置 → 配额方案。

## 六、数据备份

不发布虽然免费，但把数据只留在云上仍然有风险（误删、账号问题）。建议：

1. 云开发控制台 →「数据库」→ 选中集合 → 「导出」→ 导出为 JSON/CSV，定期存到本地。
2. 项目内已有账单导出功能，可作为日常备份手段。
3. 重要数据至少保留一份本地副本。

## 七、体验版的已知边界

| 项目 | 情况 |
|---|---|
| 有效期 | 上传后长期有效，不需要审核；重新上传新版本会覆盖体验版 |
| 使用者 | 仅限被添加为「体验成员」的微信号 |
| 功能完整度 | 与正式版一致，云函数、数据库、定时触发器、订阅消息都能跑 |
| 站内消息中心 | 正常可用（生日、日程提醒会出现在铃铛里） |
| 微信服务通知推送 | 需要在微信公众平台申请一次性订阅模板，并把模板 ID 配到云函数环境变量 `WECHAT_BIRTHDAY_TEMPLATE_ID` / `WECHAT_SCHEDULE_TEMPLATE_ID`，否则只有站内消息、没有微信推送 |
| 被搜索 / 被分享给非成员 | 不可以，只有体验成员能打开 |

> 也就是说：**你们两人的使用体验和正式版没有区别**，只是别人搜不到、用不了。
